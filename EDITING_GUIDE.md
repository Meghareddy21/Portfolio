# Siva Meghana Portfolio — Easy Editing Guide

## 1. Where to edit
Open `index.html` in VS Code. The sections are clearly marked:
- HERO
- ABOUT
- EXPERIENCE
- PROJECTS
- SKILLS
- EDUCATION
- ACHIEVEMENTS
- CONTACT

## 2. Add a new project
Find the `PROJECTS` section, copy one existing project card, paste it below the last project, then change the title, description, technologies and GitHub/demo link.

## 3. Add a new job/internship
Find `EXPERIENCE`, copy an existing experience block, and change company, role, dates and bullet points.

## 4. Update skills
Find `SKILLS` and edit the skill tags.

## 5. Update LinkedIn/GitHub/email
Use VS Code Search (Ctrl+Shift+F) and search for the old URL/email. Replace it with the new value.

## 6. Update resume
Replace `SivaMeghana_Resume.pdf` with your newest PDF using the same filename.

## 7. Profile photo / assets
The `assets` folder contains `profile-placeholder.svg`. Replace it with your own photo when ready. If you use a JPG/PNG, update the image filename in `index.html`.

## 8. Preview before publishing
Double-click `index.html`, or use VS Code + Live Server. Check the page before committing changes to GitHub.

## 9. Publish updates
If Netlify is connected to your GitHub repository, push/commit the changes to GitHub and Netlify will redeploy the site automatically.
